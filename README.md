# 3distruction
destruction game for fun

## Description
A 3D physics sandbox where you can build structures and destroy them with various tools including explosions, TNT, rockets, and nukes!

## Features
- **Interactive 3D Environment**: Powered by Three.js and Cannon.js physics engine
- **Building Tools**: Create houses and towers
- **Destruction Tools**: 
  - 💥 Explosions - Click to create instant explosions
  - 🧨 TNT - Spawn TNT blocks that detonate after 3 seconds
  - 🚀 Rocket Strike - Launch rockets from above
  - ☢️ Nuke - Massive destruction with screen flash effect
- **Visual Effects**: Particle systems, shadows, and lighting
- **Interactive Controls**: Mouse/touch controls to look around and interact

## How to Use
1. Open `index.html` in a modern web browser
2. Use the control panel on the left to select tools and build structures
3. Click anywhere on the ground to use the selected tool
4. Build structures and then destroy them with various tools
5. Use mouse to rotate camera, scroll to zoom

## Requirements
- Modern web browser with ES6 module support
- Internet connection (for loading Three.js and Cannon.js from CDN)

## Technologies
- Three.js (3D rendering)
- Cannon.js (physics simulation)
- Tailwind CSS (UI styling)
